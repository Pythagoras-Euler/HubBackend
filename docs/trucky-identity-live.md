# Trucky 身份、进行中运输与横幅

- Steam 登录通过 Trucky 官方 `GET /api/v1/user/steam/{id}` 校验公司成员身份。新成员获得“实习司机”，使用同一个 Steam ID 认领历史运单；不会改动 Public ID 或重放奖励。
- 后台按 Trucky 职位名称（忽略大小写、首尾空格）匹配唯一 Hub 角色。无匹配的职位在“配置 → 追踪器 → Trucky 职位映射”待管理员确认；可创建同名/自定义职位、映射已有职位、归为实习司机。
- 新建职位只加入司机权限。管理员角色不自动映射；同步只撤销自己添加的角色，保留手工角色。上游请求失败不视为离职。成员离开后移除同步角色；自动入职且无手工角色的账号回到非成员状态。
- 每轮同步后等待 90 秒；页面每 60 秒刷新进行中运输。进行中快照独立存于 Redis，不计入已完成统计；完成后进入正常历史导入并获得 Public ID。快照超过 5 分钟标记同步延迟，24 小时过期。
- 缺失值显示 `-*-*-`。Trucky 部分历史挂车名称本身为空；旧转换器还漏存了 `trailer_in_game_id`，现已保留并可回填。展示优先使用名称，再使用游戏 ID、车身类型。不会猜测缺失车牌或品牌。
- Trucky 不提供完整行驶轨迹；详情地图显示有坐标的事件点。限制说明保留在本文，不放在用户页面。
- 横幅支持 `?language=zh` 与 `?language=en`，个人名片可切换。Noto CJK 字体保留中文姓名、职位、公司名，缓存按语言隔离。

OCI 更新前必须备份数据库、运行时配置和镜像。`maintenance/deploy-trucky-identity.sh prepare` 构建并测试，`activate` 执行新增表和挂车字段回填，再重启 backend/frontend/bannergen。不要重跑 Public ID 强制迁移。历史记录中的运单 ID、时间、利润需与备份一致。
